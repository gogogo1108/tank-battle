# 坦克大战 (Battle City)

经典坦克大战网页版，纯 HTML + CSS + JavaScript 实现，单文件即可运行，无需任何依赖。

## 玩法

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| P | 暂停 / 继续 |
| 回车 | 开始 / 重新开始 |

## 特性

- 玩家坦克与敌方 AI 坦克（自动移动 + 射击 + 瞄准）
- 可破坏的**砖墙**、不可破坏的**钢墙**（3 级火力可击穿）、**水**、**草丛**
- 保护基地（老鹰）—— 基地被毁则游戏结束
- 道具系统：火力升级 ★、加命 +、护盾 ◈、炸弹 ✹
- 计分、关卡、音效、粒子爆炸效果

## 运行

直接用浏览器打开 `index.html` 即可，或部署到 GitHub Pages 在线游玩。
